# MC Ecosystem

Monorepo del ecosistema de un servidor de Minecraft, que integra un plugin de servidor, una API backend, una aplicación web y un bot.
Centraliza el código y los datos compartidos entre estos componentes para mantener consistencia entre juego, backend y comunidad.
La carpeta `packages/shared` contiene lógica y tipos reutilizados por varios componentes.
`infra/` agrupa configuración de infraestructura y backups; `docs/` reúne la documentación técnica y operativa.
Proyecto en fase inicial de estructuración del monorepo.
